Módulo Importação

O processo carrega os ficheiros para a diretoria de importação.

Os ficheiro Excel a importar devem assumir a seguinte nomenclatura: [Entidade]_[Módulo]_[Domínio]_[YYYYMM]_[Informação_adicional].xlsx.
O nome do Módulo não deve conter nenhum carateres especiais. Ex:. Mrel_Tlac fica MrelTlac e Corep Of torna-se CorepOf.
Selecione um ficheiro para importação (tamanho máx. 3,5 Mb).
